# pick-ui-library (Emil Kowalski)

## O que é
Skill que escolhe a biblioteca certa para cada necessidade de interface, sem dar uma lista de dez opções. A nota 9 da pesquisa vale para o repositório do Emil (apple-design, emil-design-eng, pick-ui-library).

## O que aproveitamos
- A lista curta: componentes base com base-ui, menu ⌘K com cmdk, avisos com Sonner, animação com Motion, números animados com NumberFlow, globo 3D com Cobe, gráficos com recharts, arrastar e soltar com dnd kit, listas longas com Virtuoso, estado com zustand, classes condicionais com clsx, variantes com cva, tema claro/escuro com next-themes.
- Regra: "uma recomendação, não um menu", e olhar o `package.json` antes de recomendar. Já está no `SKILL.md` da `ui-ux-pro-max`.

## O que NÃO aproveitamos e por quê
- Nada descartado. Para site com shadcn, a ordem é: usar o que o projeto já tem.

## Riscos e cuidados
- Só texto, MIT. Cada biblioteca recomendada tem licença e tamanho próprios; conferir ao instalar.

## Transcrição: o que aprendemos (nas nossas palavras)
- Escolha de biblioteca deve ser uma decisão curta e justificada.
- Antes de sugerir qualquer pacote, leia o que o projeto já usa.
- Existe uma biblioteca "padrão" para cada problema comum de interface.
