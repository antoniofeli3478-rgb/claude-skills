# blender-mcp (skill de uso do MCP)

## O que é
Skill que ensina a usar o MCP do Blender e avisa das armadilhas, principalmente do export GLTF. A recomendação dela: exportar pela linha de comando sem janela, porque o MCP dá timeout.

## O que aproveitamos
- A lição 'export GLTF pelo MCP dá timeout; exporte sem janela' ficou na lista de limitações da pesquisa A.

## O que NÃO aproveitamos e por quê
- Não entrou no SKILL.md: o foco da `blender-ia` é render PNG, não exportação para web.
- A pesquisa de Blender premium (agente B) lista esta skill como 'não conferida / não lida'.

## Riscos e cuidados
- Foi lida pela pesquisa A (SKILL.md avulso); nada executado.
- Só útil se instalarmos o MCP no computador do Daniel.

## Transcrição: o que aprendemos (nas nossas palavras)
- Mostra como orientar o Claude a usar o MCP com segurança.
- Regra prática: tarefas pesadas ou demoradas (export, render) vão por linha de comando sem janela; o MCP fica para montar e olhar a cena.
